# BUG-007 — [Ergonomie] Zones tactiles des boutons +/− trop petites (28×28 px)

| Champ JIRA | Valeur |
|---|---|
| Type | Bug |
| Sévérité | **Mineur** |
| Priorité | Moyenne |
| Composant | Ergonomie |
| User Story liée | US-02 |
| Cas de test | CT-17 |
| Version détectée | v1.4.0-rc1 (Campagne 1) |
| Environnement | QUALIF — iOS (iPhone 13) **et** Android (Pixel 7) — reproductible 100 % |
| Statut | ✅ Fermée — corrigée en v1.4.0-rc2, vérifiée en Campagne 2 |

## Prérequis
Écran « Acheter un titre »

## Étapes de reproduction
1. Ouvrir le catalogue
2. Mesurer les boutons +/−

## Résultat attendu
≥ 44×44 pt (Apple HIG) et ≥ 48×48 dp (Material Design)

## Résultat obtenu
28×28 px sur les 6 boutons → erreurs d'appui fréquentes (ajout d'une mauvaise quantité).

## Impact utilisateur / métier
Gêne, erreurs de quantité ; pénalisant pour les personnes à motricité réduite. Contournement : vérifier le panier.

- Correctif : Zone tactile 48×48.
- Re-test CT-17 sur iOS et Android en Campagne 2 : ✅ OK
- Non-régression complète (46 exécutions) : ✅ OK
